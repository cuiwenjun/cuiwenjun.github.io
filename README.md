# Jar File Opener Online SEO V2

Static website for GitHub Pages.

## Structure

- `/` Online JAR opener tool + SEO content
- `/open-jar-files-on-android/`
- `/view-manifest-mf/`
- `/decompile-class-files/`
- `/extract-jar-files/`
- `/sitemap.xml`
- `/robots.txt`

## Features

- Open `.jar` / `.zip` files in browser
- No upload, local processing
- View MANIFEST.MF
- Browse JAR contents
- Preview text files
- Hex view for binary / `.class` files
- Download selected file
- Extract all files as ZIP
- SEO tutorial pages
- Android app download links

## Deploy

Upload all files to your GitHub Pages repository for `jarfileopener.com`.

Submit this sitemap in Google Search Console:

https://jarfileopener.com/sitemap.xml

## JSZip

This version uses JSZip from CDN on the homepage:
